# Vinay Sai Pavan — Personal Portfolio

A responsive dark-theme personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in your browser. No build step or dependencies are required.

## Customize
- Update personal details and social URLs in `index.html`.
- Replace the profile placeholder with your photo.
- Replace project placeholders with real work.
- Add verified skills, certificates and experience as they are earned.
- Add a PDF named `resume.pdf` to the root and add a resume download link if desired.

## Contact form
The form opens the visitor's email app with a prefilled message. It does not send messages or store submissions on a server.

## Deploy
This is a static site and can be deployed directly from the repository root on Vercel.
